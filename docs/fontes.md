## Política de manutenção

1. Prefira fontes primárias; use explicações em português sem substituir a especificação oficial.
2. Registre data, versão do CLI, sistema operacional e forma de acesso. Não fixe preços, nomes de modelos ou disponibilidade como verdades permanentes.
3. Confirme comandos com `claude --help`; dentro da sessão, consulte a ajuda disponível.
4. Antes de instalar extensões, revise origem, código executado, ferramentas e permissões. Um exemplo da documentação ainda precisa ser adaptado e testado.
5. Revalide exercícios após mudanças de versão. Quando faltar um recurso, registre a limitação e use a alternativa do laboratório.
6. Uma referência consultada não concede domínio ao aluno. A avaliação depende de tentativa e evidência.

API do Claude e Agent SDK são estudos opcionais posteriores. Não são pré-requisitos para os laboratórios do núcleo.
